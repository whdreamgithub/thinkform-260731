# THINKFORM LIMITED Integrated Website V3

This version integrates THINKFORM LIMITED's existing cloud, big data, IT consulting and enterprise custom-solutions business with the newer AI Data Operations business line.

## Important changes in V3

- Added a dedicated `cloud-services.html` page.
- Clearly describes three cloud commercial models:
  1. Client contracts directly with the vendor.
  2. THINKFORM procures eligible subscriptions or services where permitted.
  3. THINKFORM supplies a managed cloud solution combining usage with implementation and support.
- Added cloud and software procurement, subscription management, licensing, billing and managed-operations language.
- Added clear boundaries: no trading of user accounts, promotional credits, shared credentials or non-transferable licences.
- Removed the need to imply official vendor partnership or authorised reseller status.
- Added cloud-specific enquiry fields to the Connect With Us form.
- Updated Website Terms with third-party trademark and service-availability language.
- Preserved Big Data Services, IT Consulting, Enterprise Custom Solutions and AI Data Operations.

## Deployment

Upload all files in this folder to the web root for `thinkformasia.com`. The site is static HTML/CSS/JavaScript and does not require a database.
